# Code of conduct

## Our standard

Agent Relay welcomes respectful, constructive participation. Contributors must
communicate professionally, give actionable technical feedback, respect
different experience levels and backgrounds, and protect private or
security-sensitive information.

Harassment, discrimination, threats, deliberate disruption, publication of
another person's private information, and other abusive conduct are not
acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers. Do not put
sensitive evidence in a public issue or pull request. Maintainers may edit,
remove, reject, or lock contributions and may restrict participation when
needed to protect the project or its participants.

This code applies in repository discussions, reviews, issues, and other spaces
where someone represents Agent Relay.
