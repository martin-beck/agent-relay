# Support

Agent Relay is an unsupported development preview in a private, invite-only
repository.

Invited collaborators may open a GitHub issue for reproducible build or behavior
problems after checking existing issues. Include the affected commit, Android
version, expected behavior, actual behavior, and redacted logs. Never attach
credentials, host details, private paths, session identifiers, prompts,
transcripts, signing material, or provider configuration.

Security issues must follow [SECURITY.md](SECURITY.md), not the normal issue
tracker. There is no response-time commitment, compatibility guarantee, or
support for redistributed APKs.
