# Support

Agent Relay is an unsupported development preview. A GitHub Actions artifact or
explicitly labeled development prerelease is build evidence, not a supported
release. Its `com.example.agentrelay` application ID, standard debug
certificate, and development version carry no compatibility, migration,
retention, or response-time commitment.

Invited collaborators may open a GitHub issue for reproducible build or behavior
problems after checking existing issues. Include the affected commit, Android
version, expected behavior, actual behavior, and redacted logs. Never attach
credentials, host details, private paths, session identifiers, prompts,
transcripts, signing material, or provider configuration.

Security issues must follow [SECURITY.md](SECURITY.md), not the normal issue
tracker. There is no response-time commitment, compatibility guarantee, or
support for redistributed APKs. Reports about a development APK should include
its manifest `source_commit`, `version_name`, and SHA-256, but never attach the
APK or private runtime data unless the repository policy explicitly permits it.
